# MIMIKA — Секрети ботулінотерапії

Лендинг 5-тижневого курсу з ботулінотерапії Дениса Калашника.

- **Vite** — збірка (стискає код, додає хеші до файлів)
- **GSAP + ScrollTrigger + SplitText** — анімації при прокрутці
- **Netlify Function** (`netlify/functions/lead.mjs`) — приймає заявки з форми й пересилає їх у Telegram

## Локальний запуск

```bash
npm install
npm run dev       # сервер розробки
npm run build     # збірка в dist/
npm run preview   # перегляд зібраної версії
```

Форма локально через `npm run dev` не відправляється (функції працюють лише на Netlify
або через `netlify dev`).

## Netlify

Пуш у `master` запускає деплой. Налаштування збірки — у `netlify.toml`.

У Netlify → **Site configuration → Environment variables** мають бути задані:

| Змінна | Значення |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота від @BotFather |
| `TELEGRAM_CHAT_ID` | ID каналу/чату, куди надходять заявки |

## Структура

```
index.html              розмітка сторінки
src/main.js             точка входу
src/js/                 меню, форма, анімації, стабільна висота екрана
src/styles/main.css     стилі
src/assets/             оптимізовані зображення та шрифти
public/                 favicon, картинка для превʼю посилань
netlify/functions/      серверна функція для заявок
```

## Чому сторінка не стрибає в Telegram

Вбудований браузер Telegram змінює висоту вікна, коли ховає панель під час прокрутки.
Тому висоти секцій не залежать від висоти екрана (`vh`/`svh`). Лише перший екран
займає висоту вікна, і її один раз вираховує `src/js/screen-height.js`
(оновлюється тільки при зміні ширини — наприклад, при повороті телефона).
